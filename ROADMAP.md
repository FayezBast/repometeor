# Roadmap

The immediate goal is a verified v0.1 vertical slice, not feature breadth.

## v0.1 — public foundation

- Complete frozen dependency install, web/CLI typecheck, tests, builds, E2E accessibility checks, Docker image builds, and fresh-start smoke test.
- Validate and synchronize OpenAPI examples; capture deterministic dashboard/detail screenshots.
- Review deployment defaults, backup/restore rehearsal, package and organization names, domain/trademark, and private security contacts.

## v0.2 — operations and exports

- Scheduled retention/maintenance command with dry-run reporting.
- Documented snapshot export and CLI CSV/NDJSON output.
- Shell completion and richer terminal accessibility.
- Additional deployment examples and restore drills.

## Later, after evidence

- Browser-local watchlists, optional localization foundations, and new deterministic collections.
- Historical import tooling only for aggregate data with explicit provenance.
- Performance work driven by measured query/API traces.

Non-goals remain authentication, payments, AI ranking, Redis, Kubernetes, GitHub Trending scraping, and individual stargazer tracking. Significant roadmap changes should begin as design issues with privacy, scoring, migration, and operations impact.
